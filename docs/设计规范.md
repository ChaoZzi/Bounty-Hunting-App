# 「黑金」设计规范 v0.1

> 适用：Flutter Android 客户端
> 目标：无设计稿的情况下，用一套 Token + 动效规则，保证每个页面「高端、克制、有反馈感」
> 基准稿：375 × 812（逻辑像素）

---

## 1. 设计定位

三个关键词：**稳、稀、快**

| 关键词 | 含义 | 落到设计上 |
|---|---|---|
| 稳 | 用户在平台上放钱、做任务，要信任感 | 深色底、大留白、细分割线、无花哨插画堆砌 |
| 稀 | 金色是「赏金」的隐喻，越少越贵 | 金色只出现在金额、主 CTA、会员标识，一屏 ≤ 3 处 |
| 快 | 找任务、报任务、提现都要顺手 | 操作路径 ≤ 3 步，点击必有反馈（视觉 + 触觉 + 声音） |

**反例**（截图里的赏帮赚）：大红大绿、满屏飘浮球、密集促销角标。这是「下沉市场促销风」，转化好但没档次。你要的档次感恰恰相反：**信息密度降下来，单个元素做精**。

## 2. 色彩

### 2.1 基础色

| Token | 值 | 用途 |
|---|---|---|
| `bg.base` | `#08090C` | 页面底色（近黑，不是纯黑，纯黑会显得廉价） |
| `bg.elevated` | `#12141A` | 浮层、底部导航、弹窗 |
| `bg.card` | `#16181F` | 卡片 |
| `bg.cardHover` | `#1C1F27` | 卡片按下态 |
| `hairline` | `rgba(255,255,255,0.07)` | 1px 分割线 / 卡片描边 |
| `glass` | `rgba(255,255,255,0.06)` + blur 24 | 毛玻璃层（导航、悬浮球） |

### 2.2 文字色

| Token | 值 | 用途 |
|---|---|---|
| `text.primary` | `#F5F6F8` | 标题、金额 |
| `text.secondary` | `#A8ADB8` | 正文、说明 |
| `text.tertiary` | `#6B7280` | 辅助、时间戳 |
| `text.disabled` | `#3E434D` | 禁用 |

### 2.3 品牌金

| Token | 值 | 用途 |
|---|---|---|
| `gold.300` | `#F3D9A4` | 渐变起点、高光 |
| `gold.500` | `#D9B678` | **主色**（金额、图标） |
| `gold.700` | `#A8843F` | 渐变终点、描边 |
| `gradient.gold` | `linear-gradient(135deg, #F3D9A4 0%, #C9A15E 100%)` | 主按钮、会员标识 |

### 2.4 语义色

| Token | 值 | 用途 |
|---|---|---|
| `success` | `#3DDC97` | 审核通过、打款成功 |
| `warning` | `#FFB020` | 即将超时、待处理 |
| `danger` | `#FF4D4F` | 驳回、失败、警示 |
| `info` | `#5B8CFF` | 进行中、链接 |

### 2.5 用色铁律

1. **金额永远用金色**，且用 tabular figures（等宽数字），避免跳动。
2. **一屏金色不超过 3 处**。多了就变成"土豪金"，反而廉价。
3. **红色只用于错误和驳回**。不要用红色做「+1.58 元」——那是廉价的标志（截图里就是这个问题）。
4. **不允许纯黑 `#000` 和纯白 `#FFF`**，一律用上面的 token。
5. 深色为主，**不做浅色主题**（省一半工作量，且质感更统一）。

## 4. 空间与形状

| 项 | 值 |
|---|---|
| 基准单位 | 4pt |
| 间距梯度 | 4 / 8 / 12 / 16 / 20 / 24 / 32 |
| 页面左右留白 | 16 |
| 卡片间距 | 12 |
| 卡片圆角 | 20 |
| 按钮圆角 | 14 |
| 输入框圆角 | 12 |
| 标签/胶囊圆角 | 999 |
| 卡片描边 | 1px `hairline`（不要用阴影，深色下阴影看不见） |
| 发光 | 仅主 CTA：`0 8 32 rgba(201,161,94,0.22)` |

**层级原则**：深色模式下靠「亮度差」和「描边」分层，不靠阴影。越靠上的层，背景越亮。

```
bg.base #08090C
  └ bg.card #16181F
      └ bg.elevated #12141A（弹层，反而更暗 + 更强描边）
```

## 5. 组件规范

### 5.1 主按钮（Primary）
- 背景：`gradient.gold`，文字 `#1A1206`（深色文字，不是白字——白字在金底上对比度不足）
- 高度 52，圆角 14，字号 16 / 600
- 按下：`scale 0.97` + 亮度 -8%，120ms
- 禁用：`#2A2D35` 底 + `text.disabled`
- 一屏只允许一个主按钮

### 5.2 次按钮（Secondary）
- 透明底 + 1px `gold.700` 描边 + `gold.500` 文字
- 高 48，圆角 12

### 5.3 任务卡（核心组件）
```
┌─────────────────────────────────────────┐
│ ┌────┐  任务标题最多两行…          +3.20 │
│ │封面│  来源标签 · 类型标签           元 │
│ │56px│  ─────────────────────────────   │
│ └────┘  4186人已赚   剩余 21 个          │
└─────────────────────────────────────────┘
```
- 封面 56×56 / 圆角 14 / 占位色 `bg.elevated`
- 标题 16/600，最多 2 行，超出省略
- 金额右对齐，金色 20/700，单位「元」12/500 金色
- 标签：高度 22，圆角 6，背景 `rgba(255,255,255,0.05)`，文字 11/tertiary
- 角标「顶」「快审」：金色描边胶囊，11px
- 进度：`剩余 21 个` 用 `warning` 色（≤ 20% 时）
- 整卡点击：水波纹从点击点扩散 + `scale 0.985` 回弹

### 5.4 底部导航
- 高 56 + 安全区，背景 `glass`（blur 24）+ 顶部 1px `hairline`
- 4 个 tab：首页 / 悬赏大厅 / 更多赚钱 / 我的
- 选中：图标金色 + 文字 12/600 金色 + 底部 4px 金色小圆点
- 未选中：`text.tertiary`
- 切换：200ms `crossFade` + 图标 `scale 1.0 → 1.15 → 1.0` 弹性

### 5.5 悬浮球（我的接单 / 待处理）
- 56×56 圆，金色渐变，图标深色
- **呼吸光晕**：外圈 `gold.500` 20% 透明度，2.4s 循环，scale 1.0 → 1.25 → 1.0
- 可拖动，吸附左右边缘，半透明（静止 3s 后透明度 60%）
- 点击展开：弹性径向菜单（150ms）

### 5.6 骨架屏
- 色块 `#1A1D24` → `#232732` 循环，1.2s
- 形状与真实内容一致（不要用通用灰色方块）

### 5.7 Toast / 提示
- 顶部滑入胶囊，`bg.elevated` + `hairline` + blur
- 成功：左侧 `success` 图标；失败：`danger`
- 停留 2.5s，下滑消失

### 5.8 空状态
- Lottie 动画（体量 ≤ 60KB）+ 一行说明 + 一个次按钮
- 不要用静态插画，深色下很廉价

## 6. 动效规范（这是"高端感"的主要来源）

### 6.1 时长与曲线

| Token | 值 | 用途 |
|---|---|---|
| `dur.fast` | 120ms | 按压、开关 |
| `dur.base` | 240ms | 常规切换 |
| `dur.slow` | 320ms | 页面转场 |
| `dur.celebration` | 1200ms | 成功庆祝 |
| `ease.standard` | `Cubic(0.2, 0, 0, 1)` | 绝大多数 |
| `ease.enter` | `Cubic(0.05, 0.7, 0.1, 1)` | 入场（快进慢停） |
| `ease.exit` | `Cubic(0.3, 0, 0.8, 0.15)` | 出场 |
| `spring.press` | `Spring(stiffness: 400, damping: 30)` | 按压回弹 |

### 6.2 场景清单

| 场景 | 实现 |
|---|---|
| 页面转场 | Shared Axis X：新页 `translateX 40 → 0` + `opacity 0 → 1`，旧页 `translateX 0 → -20` + 变暗，320ms `ease.enter` |
| 列表入场 | 每项 `stagger 40ms`，`translateY 16 → 0` + `opacity 0 → 1`，400ms |
| 卡片按压 | `scale 1 → 0.985`，spring.press |
| 按钮按压 | `scale 1 → 0.97`，120ms + `HapticFeedback.lightImpact()` |
| **余额数字滚动** | 旧值位移动画 + 新值 `TweenAnimationBuilder`，800ms `easeOutExpo`，tabular 数字不抖动 |
| 报名成功 | 金色粒子从按钮位置爆开（Lottie，1.2s）+ 卡片 `scale 0.9 → 1.05 → 1.0` 回弹 + `heavyImpact` |
| 赏金到账 | 金币下落 Lottie + 数字滚动 + 连续两次 `mediumImpact` |
| 下拉刷新 | 金色圆环从 0 → 360° 旋转，触发后变光斑扩散，`refresh.wav` |
| 骨架 → 内容 | `crossFade 240ms`，不要突然替换 |
| Tab 切换 | 内容 `crossFade` + `scale 0.98 → 1.0`，200ms |
| 审核状态变更 | 状态徽章 `flip` 翻转 300ms |
| 长列表滚动 | 顶部标题栏随滚动 `blur 0 → 24` + 透明度渐变 |

### 6.3 动效铁律

1. **单次动效 ≤ 400ms**（庆祝动画除外），超过就"卡"。
2. **所有动效必须可中断**：用户手指一碰就立即响应，不许"等动画播完"。
3. **不做纯装饰的循环动画**，除非它是状态指示（如呼吸光晕）。
4. 列表滚动时**暂停所有入场动画**，避免掉帧。
5. 尊重系统「减弱动态效果」设置：开启时把所有位移类动画降级为淡入淡出。

## 7. 音效规范

### 7.1 音效清单

| 文件 | 触发点 | 时长 | 音量 | 说明 |
|---|---|---|---|---|
| `tap.m4a` | 通用点击、按钮 | 60ms | -22dB | 极轻的"嗒"，木质感 |
| `toggle.m4a` | 开关、Tab | 80ms | -22dB | |
| `success.m4a` | 报名成功、提交成功 | 500ms | -16dB | 上扬的两个音 |
| `coin.m4a` | 赏金到账 | 700ms | -14dB | 金币碰撞，要有"余韵" |
| `error.m4a` | 失败、驳回 | 200ms | -20dB | 低沉短促，别刺耳 |
| `refresh.m4a` | 下拉刷新触发 | 400ms | -20dB | "呼"的气流声 |
| `levelup.m4a` | 会员开通、信誉分升级 | 1000ms | -14dB | 和弦上行 |
| `withdraw.m4a` | 提现成功 | 800ms | -14dB | 收银机 + 金币 |

### 7.2 技术约束

- 格式 **m4a / opus**，44.1kHz，单声道，单文件 ≤ 30KB
- **启动时预加载全部音效到内存**，禁止播放时读盘（否则第一声必定延迟）
- 用 `audioplayers` 的 `AudioPlayer(mode: PlayerMode.lowLatency)`
- 同时播放上限 2 个，超出直接丢弃（不要排队）
- 同一声效 **200ms 内不重复触发**（防连点轰炸）

### 7.3 体验规则

- 设置中心提供「音效开关」，默认 **开**
- **跟随系统静音/勿扰模式**（读 `AudioManager` 判断，静音时自动禁音）
- 后台/锁屏时绝不发声
- 音量整体压低到 -16dB 左右，**音效是氛围，不是主角**

### 7.4 触觉（比音效更廉价有效）

| 场景 | 强度 |
|---|---|
| 按钮点击 | `lightImpact` |
| Tab 切换 | `selectionClick` |
| 报名成功 | `mediumImpact` |
| 赏金到账 | `heavyImpact` ×2（间隔 120ms） |
| 错误 | `heavyImpact` |

> 触觉是最容易被忽略但最能提升"高级感"的一环。iPhone 的 Taptic Engine 体验好，安卓用 `HapticFeedback` 也能有 70% 的效果。**先做触觉，再做音效**——音效翻车率高，触觉几乎不会翻车。

### 7.5 素材来源

- 爱给网（`aigei.com`）免费商用区
- 耳聆网（`ear0.com`）
- Freesound（CC0 协议，需筛选 License: Creative Commons 0）
- LottieFiles 免费区（筛选 Free）

⚠️ 每个素材下载后**记录来源和授权**，存到 `assets/sounds/LICENSE.md`。商用侵权索赔在这个行业很常见。

## 9. 适配与实现约定

- 用 `flutter_screenutil`，设计稿 375×812，`ScreenUtilInit(designSize: Size(375, 812))`
- 状态栏透明 + 沉浸式（`SystemChrome.setSystemUIOverlayStyle`）
- 深色模式固定（不跟随系统）
- 支持 360 ~ 430dp 宽度
- 长列表用 `ListView.builder` + `cacheExtent`，图片统一 4:3 裁剪后上传
- 全局 `RepaintBoundary` 包裹动画组件，避免整页重绘

## 10. 验收标准（自测清单）

- [ ] 冷启动到首页可交互 ≤ 2s
- [ ] 列表滑动稳定 60fps（DevTools 无红色帧）
- [ ] 所有可点击元素都有按压反馈（视觉 + 触觉）
- [ ] 所有异步操作都有 loading 或骨架屏，无"白屏等待"
- [ ] 所有失败都有明确文案 + 重试入口
- [ ] 静音模式下无声音
- [ ] 连续快速点击不会重复提交（按钮 500ms 内禁用）
- [ ] 断网状态下每个页面都有兜底 UI
